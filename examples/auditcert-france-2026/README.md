# AuditCert France, AI strategy (2026)

A finished deck from the Philoway consulting challenge, kept as a worked
example of the template in use. Fourteen slides, no backups: everything the
team wanted to be able to answer was folded into the main deck.

| File | |
|---|---|
| `slides.html` | the source |
| `slides.pdf` | the presentation master |
| `slides.pptx` | the editable PowerPoint |
| `speaker-notes.html` / `.pdf` | one A4 page per presenter |

Worth copying from this deck:

- **One slide per question of the brief**, with the question itself printed on
  the block that answers it. A grader can tick boxes without hunting.
- **A split board resolved with a dated off-ramp.** The committee disagreed on
  cloud versus on-premise. The deck recommends one, then names the switch point,
  the month it is re-decided and who decides, so the losing side has a rematch
  with evidence rather than a dismissal.
- **Speaker notes that do not repeat the slides.** Each page carries the
  derivation, the sources and a line on what *not* to say, so two presenters do
  not spend the same number twice.
- **A stated assumption where the brief was silent.** The case never gave a
  long-term strategy, so the team assumed one, wrote it down and asked the
  client to correct it.

The client name is fictionalised in the original brief.
