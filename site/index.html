The part nobody else does

Most HTML slide tools give you a PDF and stop. This one reads the rendered geometry out of Chrome and rebuilds every box, every line of text and every colour as a native PowerPoint shape.

  • Real shapes, real text. A teammate who has never opened a terminal can drag a box and fix a typo an hour before the presentation.
  • Checked, not promised. The build fails on overflow, on text under 11.5px, and on any text that misses WCAG AA against the colour actually painted behind it.
  • One file, offline. The logo is embedded, so a mailed HTML file still arrives with its mark.
  • No npm. Chromium, poppler, Node and python-pptx. That is the whole dependency list.
